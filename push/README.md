# push-wamdarc — خادم إشعارات وإحصائيات ومض آرك

- **الإشعارات:** فَلَق وسهم وخُطى (الأذان والتذكيرات والرسائل العامة).
- **الإحصائيات:** `POST /hit` من كل التطبيقات والموقع، و`GET /analytics` للوحة الإدارة.
- **النشر:** تلقائي من هذا المجلد (Cloudflare Workers Builds ← مستودع `admin` ← المسار `push`).
- المتغيرات السرية (`ADMIN_KEY`) في Cloudflare فقط.
- انتقل من المستودع القديم `wamdarc-push` (نوفمبر 2026). الكود هنا يشمل كل اللي كان هناك + الإحصائيات.
