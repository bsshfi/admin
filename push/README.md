# push-wamdarc — خادم إشعارات وإحصائيات ومض آرك

- **الإشعارات:** فلق وسهم وخطى (الأذان والتذكيرات والرسائل العامة)، وجدولة الرسائل لسراج ونبض عبر الربط الداخلي.
- **الإحصائيات:** `POST /hit` من كل التطبيقات والموقع، و`GET /analytics` للوحة الإدارة.
- **النشر:** تلقائي من هذا المجلد (Cloudflare Workers Builds ← مستودع `admin` ← المسار `push`).
- المتغيرات السرية (`ADMIN_KEY` و`REPORT_TO`) في Cloudflare فقط، ولا تنكتب هنا.
- **الجداول:** تُنشأ وتُرقّى في `init()` مرة واحدة لكل رقم `SCHEMA`. أي جدول أو عمود جديد: أضفه في `init()` وارفع `SCHEMA`.
- الإحصائيات والسجلات بدون حذف تلقائي.
- للتجربة محلياً: `npx wrangler dev --local` مع `ADMIN_KEY` تجريبي في `[vars]` (لا ترفعه).
