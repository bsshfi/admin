# لوحة إدارة ومض آرك

admin.wamdarc.com: إحصائيات وإرسال إشعارات لكل التطبيقات (فلق، سهم، خطى، سِراج، نَبْض).

- يكلّم `push-wamdarc` و `siraj-api` و `nabd-api` بنفس ADMIN_KEY.
- ما فيها أي مفاتيح سرية؛ المفتاح ينكتب عند الدخول وينحفظ على جهازك فقط.

## خادم push-wamdarc (مجلد `push/`)
كود الخادم هنا، وCloudflare ينشره تلقائياً مع كل رفع على `main` (Workers Builds، المسار `push`).
الإحصائيات والسجلات ما تنحذف تلقائياً، والنسخة الاحتياطية من تبويب «السجلات».
