# لوحة إدارة ومض آرك | WAMD ARC

admin.wamdarc.com: الإحصائيات والإشعارات والرسائل داخل التطبيقات لكل تطبيقات ومض آرك (سهم، فلق، خطى، حرف، سراج، نبض) والموقع.

- نفس هوية wamdarc.com: مظهر نهار (فاتح، الافتراضي) وليل (داكن) بزر أعلى اللوحة، ويُحفظ الاختيار.
- تكلّم `push-wamdarc` و`siraj-api` و`nabd-api` و`harf-api` بنفس ADMIN_KEY.
- ما فيها أي مفاتيح سرية: المفتاح يُكتب عند الدخول ويبقى للجلسة فقط، إلا إذا اخترت «تذكّر هذا الجهاز».
- قفل تلقائي بعد ٣٠ دقيقة بدون استخدام، وزر «قفل اللوحة»، وإظهار/إخفاء المفتاح، وتنبيه الأحرف الكبيرة.
- المحاولات الخاطئة الكثيرة تقفل الدخول مؤقتاً من الخادم (٢٠ محاولة خلال ساعة ← ٣٠ دقيقة).

## خادم push-wamdarc (مجلد `push/`)
كود الخادم هنا، وCloudflare ينشره تلقائياً مع كل رفع على `main` (Workers Builds، المسار `push`).
الإحصائيات والسجلات ما تنحذف تلقائياً، والنسخة الاحتياطية من تبويب «السجلات».
